# 更新日志

## v1.0.9 <Badge type="tip" text="预告" /> · 2026-11-XX

更新内容：

- 嗅探源增加静态标识，静态网站将使用 JS 直接获取资源分集信息，这将大大提高加载速度；非静态站仍使用 Webview 加载。
- 增加脚本源，通过 JavaScript 脚本模拟发送接口请求，直接获取资源信息。
- 增加BT源，支持磁力链接边下边播边上传。
- 完善缓存功能，支持 M3U8 / MP4 / BT 等资源类型下载。
- 全平台统一内置更新策略。
- 更换搜索引擎，搜索更快更精准。
- 将【采集源页面】入口从【设置】移至【我的】。

修复内容：

- 修复添加采集源过多时，播放界面换源弹窗无法滚动问题。

## v1.0.7 · 2026-10-02

更新内容：

- 软件不再维护默认采集源，转到[社区仓库](https://github.com/SX-Code/resource-rules)
- 增加源预采集功能，可在换源时看到源采集结果
- 修复自定义搜索名称时滑选和点选冲突问题
- 更新后采集源被清空，需在添加源时选择“同步采集源”
- 调整嗅探逻辑，提高嗅探成功率
