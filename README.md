<h1 align="center">AFAN</h1>

<p align="center">一款基于 Flutter 开发的番剧资源阅览与播放应用，支持用户登录注册、番剧收藏等功能，为用户提供便捷的追番观看体验。本应用所有资源均收集于互联网，仅用于学习交流，非盈利用途。如有侵权或商务合作需求，请及时与我联系。</p>

## 支持平台

- Android
- iOS（自签名）
- HarmonyOS（侧载安装）
- MacOS
- Windows
- Linux
- TV（待支持）
